How to use

Reading Levels

Read one .lvl file, drag one into the read zone, or add a directory to populate the level list.

Browse A Directory

Use Add directory to read every .lvl file in that folder and its subfolders. Click any level row to render it.

Navigate The Board

Drag the board to pan, use the mouse wheel to zoom, and press the reset control in the lower-right corner to recenter.

Inspect Objects

Hover cells for coordinates and contents. Track an object such as agent0 or boxA, or jump to a coordinate such as 28,3.
